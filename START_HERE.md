# 🎮 START HERE - GameFlowManager Setup

## ⚡ Super Quick (30 seconds)

```
1. Unity → Tools → Wilderness → Setup → Complete GameFlow Setup
2. Click "🚀 RUN COMPLETE SETUP"
3. Wait 30 seconds
4. DONE! 🎉
```

**That's it!** Your game now has:
- ✅ Main Menu with Play/Quit buttons
- ✅ Victory/GameOver screens with Restart/Main Menu buttons
- ✅ Persistent game flow management
- ✅ Build Settings configured

## 🧪 Test It Works

1. Press Play in Unity
2. You should see the Main Menu
3. Click "▶ PLAY" → Game starts
4. During gameplay, open GameManager Inspector
5. Click "🏆 Victory" button → Victory screen appears
6. Click "Restart" → Game restarts
7. Click "Victory" again → Click "Main Menu" → Back to Main Menu
8. Click "🚪 QUIT" → Play Mode stops

**All working?** ✅ You're ready to go!

---

## 🔄 Need to Undo?

```
1. Tools → Wilderness → Setup → Complete GameFlow Setup
2. Click "🔄 Rollback All"
3. Confirm
4. DONE! Everything removed
```

## 🎨 Customize

After setup, you can customize:
- Button colors (Select button → Inspector → Colors)
- Title text (Select Title → Inspector → Text)
- Add logo (Create → UI → Image)
- Add animations (Create Animator Controller)
- Add sounds (Create AudioSource)

**Guide**: [COMPLETE_SETUP_TOOL.md](COMPLETE_SETUP_TOOL.md#customization-after-setup)
